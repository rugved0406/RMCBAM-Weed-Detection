6. RMCBAM architecture

  • ECA-style channel attention: average- and max-pooled descriptors share one 1-D convolution with no FC bottleneck. The kernel adapts to channel count.
  • Multi-scale spatial attention: 3×3, 7×7 and dilated 5×5 (rate 2) branches run in parallel on the channel-mean and max maps, followed by a 1×1 fusion and a sigmoid.
  • Residual attention gating: out = x + γ ⊙ (x ⊙ Mc ⊙ Ms), where γ is per-channel and starts at 0. A newly inserted block is an exact identity, so YOLOv8s weights transfer 1:1.
  • Placement: C2f blocks at layers 4, 6, 8 (backbone P3–P5) and 15, 18, 21 (neck outputs into Detect).

9. What's needed for real results

  1. LabelMe annotations for all five classes (or complete the files in data/recovered/labelme), then run python tools/convert_labelme.py --images "data/Himani mam images/Origanal" --out data/yolo.
  2. Train both models with identical settings: python tools/train.py --data data/yolo/data.yaml --variant both --epochs 100 --device 0. Model Comparison then reads runs/detect/yolov8s_baseline and yolov8s_rmcbam directly.
  3. Or supply existing trained checkpoints / run folders and the training notebooks. If their RMCBAM class names differ, those definitions are needed to load them.
Regenerate: python tools/build_reports.py then python tools/build_report_html.py.
